# Publicar desde Android

El procedimiento vigente es [RS-05 automático](RS-05-AUTOMATICO.md).

En RobPublisher: seleccionar la aplicación y pulsar **Publicar actualización**.
El progreso y el resultado se muestran en la app. GitHub compila, firma con la
identidad existente y publica; RobStore descubre la Release estable.

El alta y la migración se realizan una sola vez. Las actualizaciones no requieren
Termux, GitHub web, confirmaciones intermedias ni gestión de firmas.
